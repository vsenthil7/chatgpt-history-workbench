
### 2️⃣ Timezone-Only Prompt (Minimal Disclosure)

```
Assume I am in a UTC offset timezone.
Ask me only for:
- UTC offset (e.g., UTC+5:30)
Do not ask for city or country.
```

---

### 3️⃣ Soft Inference Prompt (Ethical)

```
Based only on my language style, spelling, and references,
estimate a likely timezone range (±3 hours).
State clearly that this is an approximation, not a fact.
```

---

### 4️⃣ Context-Driven Time Awareness

```
If the user mentions:
- morning / evening
- today / tomorrow
- workday / weekend

Use these as relative markers.
Do not assume exact clock time unless explicitly stated.
```

---

### 5️⃣ System-Neutral “Now” Prompt

```
Treat “now” as:
- The moment of the user’s message
- Without assuming their clock time

If precision is required, ask a follow-up question.
```

---

### 6️⃣ Uncertainty Fallback (Professional)

```
If location or time is unclear:
1) State uncertainty clearly
2) Offer two alternative interpretations
3) Ask one clarifying question only
```
