✅ No training data needed  
✅ Very predictable  
❌ Can’t learn new patterns by itself

**Machine Learning** means:

> “Instead of writing rules, we give examples (data), and it learns patterns.”

Example:  
Give thousands of emails labeled **spam / not spam** → model learns spam patterns.

So:  
✅ **ML = learning from data**

## Step 4 — ML has 2 main styles

### 4A) Classical ML (non-neural)
These models learn using math/statistics with **human-chosen features**.

Examples:
- Linear Regression
- Decision Trees / Random Forest
- XGBoost
- SVM

Used mostly for:
- Excel-like business data (tables)
- Predictions, classification

✅ Often explainable  
✅ Works with smaller data  
✅ Fast

---

### 4B) Neural Networks (NN)
A **Neural Network** is a *type of ML model* inspired loosely by brain neurons.

It learns by adjusting many weights.

✅ Can learn more complex patterns than classical ML  
❌ Needs more data/compute than classical ML (often)

So:  
✅ **Neural Network = a model family inside ML**

## Step 5 — Deep Learning (DL) is just “big neural networks”
**Deep Learning = Neural Networks with many layers.**

That’s it.

- Neural Network (few layers) → not “deep”
- Neural Network (many layers) → “deep learning”

So:
✅ **DL is a subset of Neural Networks**  
✅ **Neural Networks ⊂ ML**  
✅ **Deep Learning ⊂ Neural Networks**

---

## Step 6 — “NLP models” are about *language domain*
**NLP = Natural Language Processing** (text, language).

Important: NLP is NOT one model type. It’s a *field*.

NLP models can be:
- Classical ML (e.g., spam classifier using TF-IDF + Logistic Regression)
- Neural Networks
- Deep Learning

So:
✅ **NLP = “where used” (language), not “what model”**

---

## Step 7 — LLMs are a special kind of Deep Learning NLP model
**LLM = Large Language Model**

- It is a **Deep Learning model**
- Used for **NLP**

- Trained on massive text

So:
✅ **LLM ⊂ Deep Learning ⊂ Neural Networks ⊂ ML**  
and LLMs are mainly used in NLP tasks.

**Programmatically: how ML vs NN vs DL vs NLP vs LLM differ**

They differ mainly in **(A) what data you feed**, **(B) what code you write**, and **(C) how you train/infer**.

---

## Step 1 — The common skeleton (almost all models)

No matter what the model is, programmatically you usually do:

1) **Get data**  
2) **Preprocess**  
3) **Choose model**  
4) **Train** (`fit` / training loop)  
5) **Predict** (`predict` / inference)  
6) **Evaluate**

So the “difference” is mostly **preprocessing + model class + training loop complexity**.

---

## Step 2 — Classical ML (non-neural): programmatic signature

### Data shape
- **Tabular numeric/categorical**: rows × columns

### Typical code pattern
- Manual feature engineering
- One-line training: `model.fit(X, y)`
- Fast training, small hardware

### What you write
- Feature extraction + scaling/encoding
- Choose algorithm: XGBoost / RandomForest / LogisticRegression

**Key program difference**
✅ Training loop is hidden inside library  
✅ Inputs are fixed-size vectors  
❌ Not great with raw images/audio/text meaning

---

## Step 3 — Neural Networks: programmatic signature

### Data shape
- Still often tabular, but can be richer
- Input becomes tensors (arrays)

### Typical code pattern
- Define network layers
- Explicit training loop (or `.fit()` in Keras)
- Need learning rate, batch size, epochs

### What you write
- **Architecture**: layers + activation
- **Loss function**
- **Optimizer**
- **Backprop training**

**Key program difference**
✅ You define the “model structure”  
✅ Training is iterative (epochs)  
❌ Needs tuning + more compute

---

## Step 4 — Deep Learning: same as NN, but bigger + specialized layers

### Data shape
- **Images:** (batch, height, width, channels)
- **Audio:** (batch, time, features)
- **Text:** sequences

### Typical code pattern
- CNNs, RNNs, Transformers
- GPUs usually needed
- Data loaders + augmentation common

**Key program difference**
✅ Architecture includes domain layers (Conv, Attention)  
✅ Training pipelines are heavier  
✅ Often needs much more data

---

## Step 5 — NLP (language): programmatic signature

NLP is not one model; **the pipeline is what changes**.

### Old/classical NLP (ML-based)
- Convert text → numbers using **TF-IDF / n-grams**
- Then use classical ML: logistic regression / SVM

**Program difference**
✅ You explicitly build the text vectorizer  
✅ Model sees a sparse vector

### Modern NLP (deep learning)
- Text → **tokens → embeddings**
- Then model learns meaning/context

**Program difference**
✅ Tokenizer becomes a key component  
✅ Sequence handling matters (padding, masks)

---

## Step 6 — LLMs: programmatic signature

LLMs are deep learning NLP models where you usually **don’t train from scratch**.

### Programmatically you do one of these:

1) **Inference only (most common)**  
   - Load pretrained model
   - Prompt → generate

2) **Fine-tuning (sometimes)**  
   - Train on your dataset with adapters (LoRA etc.)
   - More GPU/time

3) **RAG (very common in products)**  
   - Your documents → embeddings → vector search
   - LLM uses retrieved text to answer

**Key program difference**
✅ You write “prompting + safety + retrieval” logic  
✅ Training is optional; orchestration is the work  
✅ Memory/context window constraints matter

---

# One concrete “same task” example: Text classification

### A) Classical ML way
- Text → TF-IDF → LogisticRegression

### B) Deep NLP way
- Text → tokens → Transformer classifier head

### C) LLM way
- Prompt: “Classify this as spam/ham…” (zero-shot)  
  or fine-tune

**Program difference**
- Classical ML = feature pipeline + fit  
- DL NLP = tokenizer + tensors + training loop  
- LLM = prompt/inference or fine-tune + deployment orchestration
