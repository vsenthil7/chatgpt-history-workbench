Employer **never** touches Layer 1. They only ever see post-processed summaries that **PASS a safety gate**.

### 🔹 Layer 1 – Raw Data (Local Only)

> No network code is allowed in this layer.

```python
# pseudo-structure
```

No HTTP clients imported here.  
No “send_to_server” functions exist in this module.

This is enforced at architecture level:
- `raw_data` package: **no dependency on `network` or `cloud` packages**

### 🔹 Layer 2 – Aggregation + Consent Engine (Still Local)

This layer **reads raw data**, produces **safe summaries**, and only these can be requested by sync.

Example aggregates:

```python
@dataclass
class DailySummary:
    date: date
    total_focus_minutes: int
    completed_tasks: int
    on_time_ratio: float   # 0–1
    avg_flow_score: float
    context_switch_count: int
    burnout_flags: list[str]  # high_level labels
```

The critical constraint:

> This layer *knows* what is allowed to leave the device and what is forbidden.

You can enforce this with **whitelisted schemas**:

```python
ALLOWED_EXPORT_TYPES = {
    "DailySummary",
    "TaskOutcome",
    "EstimationStats",
}

FORBIDDEN_FIELDS = {
    "keystroke_intervals_raw",
    "window_titles",
    "screenshot_paths",
    "wearable_raw_stream",
}
```

When building payloads:

```python
def build_export_payload(day: date) -> dict:
    summary = aggregator.get_daily_summary(day)
    
    payload = asdict(summary)

    # Safety gate: scrub forbidden fields if present
    for field in FORBIDDEN_FIELDS:
        payload.pop(field, None)

    return payload
```

So even if a developer accidentally adds a dangerous field into a struct,  
the **export function drops it by policy**.

```python
class SyncClient:
```

     - Long-term trend lines
     - Team and org aggregates
   - Never introduces raw data fields, only derived metrics.

   - Controls:
     - Who can see which subset of employee summaries
   - Enforces:
     - “Manager sees team aggregates & member summaries”
     - “HR sees only de-identified metrics”

   - User-specific privacy settings mirrored in cloud
   - E.g. “Do not share my burnout flags with employer”
