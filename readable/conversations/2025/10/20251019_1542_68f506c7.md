To use the **OpenAI Python library** in **Visual Studio Code (VS Code)**, you’ll install it with `pip` inside your project’s Python environment and then use it in your code.

## 🪛 Step-by-Step: Install in VS Code

### ✅ 1️⃣ Prerequisites
Make sure you have:
- **Python installed** (3.8 or higher) → Check with: `python --version`
- **VS Code installed**
- **Python extension in VS Code** (Microsoft’s one)

---

### 📁 2️⃣ Open or Create a Project Folder in VS Code
- Open VS Code
- Go to **File → Open Folder…**
- Select or create your project folder

---

### 🐍 3️⃣ Create (Optional but Recommended) a Virtual Environment
In **VS Code Terminal** (`Ctrl + ``):

```bash
python -m venv venv
```

Activate it:
- **Windows (PowerShell)**:
  ```bash
  .\venv\Scripts\activate
  ```
- **Mac/Linux**:
  ```bash
  source venv/bin/activate
  ```

You should see `(venv)` in your terminal.

---

### 📦 4️⃣ Install the OpenAI Package

```bash
pip install openai
```

---

### 🔑 5️⃣ Set Your OpenAI API Key
Create a `.env` file or set in terminal environment:

```bash
setx OPENAI_API_KEY "your_key_here"   # Windows
export OPENAI_API_KEY="your_key_here" # macOS/Linux
```

---

### 🧪 6️⃣ Test with a Simple Python File

Create a file: `main.py`

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Hello, how are you?"}
    ]
)

print(response.choices[0].message.content)
```

Run it:
```bash
python main.py
```
