### 🧩 1️⃣  UNDERSTAND (Concept & Explanation)

**What is a Variable?**  
A variable is a *name that remembers a value* for you.  
Think of it as a small labelled box in your computer’s memory.  
You can change what’s inside — but the label (name) stays the same.

```python
name = "Senthil"
age = 44
```

Here:
- `"Senthil"` is **text** (type: `str`).
- `44` is **number** (type: `int`).

You can check what type something is using:
```python
print(type(name))
print(type(age))
```

---

**Expressions and Operators**  
An expression is something that *produces a value*.
Example:
```python
x = 5 + 3 * 2
print(x)  # 11
```
Python first multiplies (`3*2`) then adds (`5+6`).

Operators you’ll use often:
| Type | Example | Meaning |
|------|----------|----------|
| Arithmetic | + - * / // % ** | math operations |
| Comparison | == != > < >= <= | compare values |
| Assignment | = += -= *= /= | store/update |
| Logical | and, or, not | combine conditions |

---

**Strings and f-strings (formatted strings)**  
A string is text inside quotes.  
To print both text and variable values neatly, use **f-strings**:

```python
name = "Senthil"
word = "focused"
print(f"Hi {name}! Today feels {word}. Welcome to Python.")
```

Python replaces `{name}` and `{word}` with their values.

---

**Input / Output**
To take user input:
```python
name = input("Your name: ")
word = input("One word for today: ")
print(f"Hi {name}! Today feels {word}. Welcome to Python.")
```
- Everything from `input()` is a string.
- `.strip()` removes extra spaces.

---

**Why this matters**  
This is the foundation for *every* automation, analysis, or data flow you’ll ever build.  
Variables = memory,  
Expressions = logic,  
Print = communication.  
You’ve just learned the building blocks of **mind ↔ machine language**.
