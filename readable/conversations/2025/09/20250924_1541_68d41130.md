## 3) Variables & basic types (25–30 min)

### What is a variable?
A **named box** that holds a value. Python creates it the moment you assign.

```python
name = "Asha"        # str (string)
age = 28             # int (integer)
height = 1.65        # float
is_student = True    # bool
```

### Naming rules (and good style)
- Letters, digits, underscores; **cannot start with a digit**
- Case-sensitive: `age` ≠ `Age`
- Use **snake_case**: `total_price`, `user_name`
- Pick meaningful names!

### Inspecting values
```python
print(type(name))      # <class 'str'>
print(type(age))       # <class 'int'>
```

### Reassignment (dynamic typing)
```python
x = 10      # int
x = "ten"   # now str; Python allows this
```

### Numbers: quick tour
```python
a = 7
b = 3
print(a + b)    # 10
print(a - b)    # 4
print(a * b)    # 21
print(a / b)    # 2.333...
print(a // b)   # 2   (integer division)
print(a % b)    # 1   (modulus)
print(a ** b)   # 343 (power)
```

### Strings: quick tour (more on Day 3)
```python
first = "Ada"
last = "Lovelace"
full = first + " " + last
print(full)                 # Ada Lovelace
print(len(full))            # 12
print(full.upper())         # ADA LOVELACE
```

### f-strings (best way to format)
```python
name = "Asha"
age = 28
print(f"Hello {name}, you are {age} years old.")
```

## 4) Input & type conversion (20–25 min)

`input()` always returns a **string**. Convert when needed.

```python
name = input("Your name: ")
age_str = input("Your age: ")
age = int(age_str)            # convert to int
print(f"Hi {name}! Next year you’ll be {age + 1}.")
```

Common conversions:
```python
int("42")       # 42
float("3.14")   # 3.14
str(42)         # "42"
bool(0)         # False   (nonzero numbers → True)
```

> **Tip:** Converting non-numeric text with `int()`/`float()` raises `ValueError`. If it happens, check your input.

## 2) Indexing & slicing (15–20 min)

```python
t = "ABCDEFGHIJ"
print(t[0], t[1], t[-1])        # A B J
print(t[2:5])                   # CDE   (start inclusive, end exclusive)
print(t[:4])                    # ABCD
print(t[6:])                    # GHIJ
print(t[::2])                   # ACEGI  (step)
print(t[::-1])                  # JIHGFEDCBA  (reverse)

# Slicing is forgiving:
```

## 1) Arithmetic operators (20 min)

```python
a, b = 7, 3
print(a + b, a - b, a * b)   # 10 4 21

print(a ** b)                # 343      (power)
print(-7 // 2)               # -4       (floors down)
print(-7 % 2)                # 1        (so that (a//b)*b + (a%b) == a)
print(divmod(a, b))          # (2, 1)   quotient & remainder
```

```python
print("py" + "thon")   # python
```

## 6) Common pitfalls (5–8 min)

## 4) The loop `else` clause (power move) (10 min)

`else` on a loop runs **only if the loop wasn’t broken**.

```python
# Search example
nums = [2, 4, 6, 8, 10]
target = 7
for x in nums:
    if x == target:
        print("Found!")
        break
else:
    print("Not found")   # runs because we never broke
```

**Prime check with for–else:**
```python
n = int(input("n: "))
if n < 2:
    print("Not prime")
else:
    for d in range(2, int(n**0.5)+1):
        if n % d == 0:
            print("Not prime")
            break
```

## 7) Common pitfalls (5–8 min)
- **Off-by-one**: remember `range(stop)` ends **before** `stop`.  
- **Infinite loops**: ensure your `while` condition eventually becomes False or `break`.  
- **Mutating while iterating**: don’t remove items from a list you’re looping over; loop a copy:

```python

    if x < 0:
        nums.remove(x)
```

- **Need index?** Use `enumerate` instead of `range(len(seq))` unless you truly need length-based indexing.  
- **`break` breaks only one level**: to break nested loops, use a flag, `return` (inside a function), or restructure.

```python
# 2) Remove all (in place)
def remove_all(lst, x):
    i = 0
    while i < len(lst):
        if lst[i] == x:
            lst.pop(i)
        else:
            i += 1

# 3) Rotate right by k
def rotate_right(lst, k):
    n = len(lst)
    if n == 0: return lst
    k %= n
    return lst[-k:] + lst[:-k] if k else lst[:]

# 4) Flatten 2D
def flatten(two_d):
    out = []
    for row in two_d:
        for v in row:
            out.append(v)
    return out

# 5) Chunking
def chunks(lst, k):
    out = []
    for i in range(0, len(lst), k):
        out.append(lst[i:i+k])
    return out

# 6) Second largest unique
def second_largest_unique(lst):
    uniq = sorted(set(lst))
    if len(uniq) < 2: return None
    return uniq[-2]

# 7) Find duplicates with counts
def dup_counts(lst):
    counts = {}
    for x in lst:
        counts[x] = counts.get(x, 0) + 1
    return {k:v for k,v in counts.items() if v > 1}

# 9) Case-insensitive sort
def sort_ignore_case(words):
    return sorted(words, key=str.lower)

# 10) Transpose (rows→cols)
def transpose(mat):
    if not mat: return []
    rows, cols = len(mat), len(mat[0])
    out = [[None]*rows for _ in range(cols)]   # distinct rows!
    for r in range(rows):
        for c in range(cols):
            out[c][r] = mat[r][c]
    return out
```
