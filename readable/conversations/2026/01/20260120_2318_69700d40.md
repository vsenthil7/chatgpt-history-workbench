## 🔁 High-level flow (what actually happens)

### 1️⃣ Recording (browser / app)
- Your microphone captures raw audio (PCM).
- Audio is **chunked** (e.g., 1–5 second blocks), not kept as one big file.
- Light preprocessing may happen locally (noise normalization, silence trimming).

> **Important**: No full transcription happens purely in the browser for long audio.

---

### 2️⃣ Upload to server (streaming, not after finish)
- As soon as you start recording, **chunks are uploaded continuously**.
- This means transcription can start **before recording ends**.

Think of it like:
> *Netflix streaming, not file upload.*

---

### 3️⃣ Server-side speech recognition (the speed secret)
On the server:
- **GPU-based speech models** (similar class to Whisper / Conformer / wav2vec-style models)
- **Batch + parallel decoding**
- **Non-real-time decoding**

📌 Humans: ~1× speed  
📌 Machines: **10×–50× faster than real time**

So:
- **10-minute audio → ~1 minute processing** is normal
- Sometimes even faster if silence is detected

---

### 4️⃣ Language detection + translation (optional)
If you ask for translation:
- The system first does **speech → text (source language)**
- Then **text → text translation** (much faster than audio processing)

Text translation is:
- Lightweight
- Fully parallel
- Often milliseconds per sentence

---

### 5️⃣ Post-processing (why output looks clean)
After raw transcription:
- Punctuation insertion
- Sentence boundary detection
- Numbers normalization
- Optional diarization (speaker labels)
- Optional glossary / correction pass

These are **text-only** operations → very fast.

---

## ❓ Why it feels *instant*
Several optimizations stack together:

| Reason | Effect |
|-----|-----|
| Streaming upload | No waiting for full audio |
| Chunked decoding | Parallel GPU execution |
| Silence skipping | Dead air ignored |
| Non-realtime inference | Model not bound to playback speed |
| Text translation | Much cheaper than audio |

So the “magic” is **pipeline design**, not a single trick.

---

## 🔐 Privacy & data handling (important)
Typical behavior (varies by provider, but generally):
- Audio is **sent to server**
- Used **only for transcription** (unless you opt-in for training)
- Stored briefly or not at all depending on settings
- Browser alone is **not powerful enough** for this speed at scale

If it were 100% browser-only:
- CPU would spike
- Laptop fans would scream
- 10-minute audio would take ~8–15 minutes

What you’re noticing is real: **“Record + translate” and “upload an audio file” are not the same pipeline inside ChatGPT**, and they can have different limits / failure modes.

## Why “Record translation” works but uploaded audio doesn’t
### 1) They’re different features (and not equally available everywhere)
- **ChatGPT Record** is a specific feature (currently tied to the desktop app experience) that’s designed to **capture audio, transcribe, and summarize** in one flow. citeturn0search5  
- **File uploads** are a separate system with their own handling rules and capability differences. citeturn0search1

So it’s possible for:
- **recorded audio → transcribe/translate works**
- but **uploaded audio file → doesn’t trigger transcription/translation reliably** (or is not supported in your current surface/model mode)

## Why it becomes “garbage” after a few recordings
Usually it’s one (or a combo) of these:

### A) You hit a usage cap and the system silently downgrades
ChatGPT has **usage limits** and can switch you to a lighter model/experience after you hit caps. For example, ChatGPT model usage limits can cause fallback behavior after a threshold. citeturn0search20  
Voice availability/limits also vary by plan and demand (they do change over time). citeturn0search2turn0search10

When it downgrades, you can see:
- worse punctuation
- missing words / wrong language detection
- “random” fragments (classic low-confidence decoding)

### B) Audio quality drift (the #1 practical cause)
After multiple takes, people often record:
- farther from mic
- more background noise (kitchen fan, TV)
- more Tamil+English code-switching
- faster speech / overlapping voices

ASR models degrade *hard* when SNR drops, and the output can look like “garbage” even though nothing is “wrong” with your account.

### C) Context/segment limits (chunking issues)
Record/transcribe systems process in **chunks**. If chunk boundaries cut through sentences (or there’s heavy back-and-forth language switching), you get:
- repeated phrases
- swapped words
- broken grammar

### D) Temporary server load / throttling
Even if OpenAI doesn’t show a “Zoom-style timer,” systems often enforce:
- per-minute / per-hour throughput limits
- burst limits (many recordings quickly)
- fairness throttles at peak time

That can manifest as slower processing *or* reduced quality.

## Do you have a fixed limit like “Zoom 40 minutes”?
OpenAI doesn’t present it as one simple number in the UI the way Zoom does, because limits can depend on:
- plan (Free/Plus/Business/Enterprise)
- feature (Voice vs Record vs file upload)
- current demand
- model selected

But **yes — there are limits and anti-abuse protections**, and they can feel like “it worked 3 times then became bad.” citeturn0search2turn0search10turn0search20

## What to do (fast fixes)
1) **Do fewer, longer recordings** (instead of many short bursts back-to-back).  
2) Keep mic distance consistent; avoid fan/TV.  
3) If you mix Tamil+English, explicitly say at the start: “Transcribe with Tamil+English mixed.”  
4) If quality suddenly drops, **start a new chat** (fresh context helps chunking).  
5) If you see the UI indicating a fallback / limit, wait a bit and retry.

### 🔹 `transcribe_local.py` (CPU-only Whisper, tuned)
```python
import argparse, whisper, pathlib, re

def load_glossary(path):
    if not path: return ""
    with open(path, encoding="utf-8") as f:
        return " ".join([l.strip() for l in f if l.strip()])

parser = argparse.ArgumentParser()
parser.add_argument("--audio", required=True)
parser.add_argument("--model", default="small")
parser.add_argument("--language", default="ta")
parser.add_argument("--task", default="translate")
parser.add_argument("--glossary")
parser.add_argument("--outdir", default="output")
args = parser.parse_args()

outdir = pathlib.Path(args.outdir)
outdir.mkdir(exist_ok=True)

print("Loading Whisper model:", args.model)
model = whisper.load_model(args.model)

prompt = (
    "This audio contains Tamil and English mixed speech. "
    "Preserve English technical terms exactly. "
    + load_glossary(args.glossary)
)

print("Transcribing:", args.audio)
result = model.transcribe(
    args.audio,
    language=args.language,
    task=args.task,
    initial_prompt=prompt,
    beam_size=5,
    best_of=5,
    fp16=False
)

text = result["text"].strip()

# simple cleanup
text = re.sub(r"\s+", " ", text)

outfile = outdir / (pathlib.Path(args.audio).stem + ".txt")
outfile.write_text(text, encoding="utf-8")

print("Saved:", outfile)
```

import json, re, csv, sys
from datetime import datetime, timedelta

whisper = json.load(open(sys.argv[1], encoding="utf-8"))
speakers = json.load(open(sys.argv[2], encoding="utf-8"))

ACTIONS = re.compile(r"\b(do|send|prepare|review|submit|follow up|share|fix|raise)\b", re.I)
DATE_PAT = re.compile(r"(\d{1,2}[/-]\d{1,2}[/-]\d{2,4}|tomorrow|next week|today)", re.I)

def find_speaker(t):
    for s in speakers:
        if s["start"] <= t <= s["end"]:
            return s["speaker"]
    return "Speaker"

def norm_date(m):
    m = m.lower()
    today = datetime.today().date()
    if m == "today": return today
    if m == "tomorrow": return today + timedelta(days=1)
    if m == "next week": return today + timedelta(days=7)
    try:
        return datetime.strptime(m.replace("-","/"), "%d/%m/%Y").date()
    except:
        return ""

rows = []
for seg in whisper["segments"]:
    if ACTIONS.search(seg["text"]):
        owner = find_speaker(seg["start"])
        dm = DATE_PAT.search(seg["text"])
        due = norm_date(dm.group(1)) if dm else ""
        rows.append([owner, seg["text"].strip(), due])

with open("output/action_items.csv","w",newline="",encoding="utf-8") as f:
    w = csv.writer(f); w.writerow(["Owner","Action","Due Date"]); w.writerows(rows)

with open("output/action_items.txt","w",encoding="utf-8") as f:
    for r in rows:
        f.write(f"- {r[0]} | {r[1]} | Due: {r[2]}\n")

## `signaling/server.js`
```js
import { WebSocketServer } from "ws";

const wss = new WebSocketServer({ port: 8080 });
const rooms = new Map(); // roomId -> Set(ws)

function safeSend(ws, msg) {
  if (ws.readyState === ws.OPEN) ws.send(JSON.stringify(msg));
}

wss.on("connection", (ws) => {
  ws.on("message", (raw) => {
    let msg;
    try { msg = JSON.parse(raw.toString()); } catch { return; }

    const { type, roomId, payload } = msg;
    if (!roomId) return;

    if (type === "join") {
      if (!rooms.has(roomId)) rooms.set(roomId, new Set());
      rooms.get(roomId).add(ws);
      safeSend(ws, { type: "joined", roomId });
      return;
    }

    // relay to other peers in same room
    const peers = rooms.get(roomId);
    if (!peers) return;

    for (const peer of peers) {
      if (peer !== ws) safeSend(peer, { type, roomId, payload });
    }
  });

  ws.on("close", () => {
    for (const [roomId, peers] of rooms.entries()) {
      peers.delete(ws);
      if (peers.size === 0) rooms.delete(roomId);
    }
  });
});

console.log("Signaling server ws://localhost:8080");
```

# 4) Transcription server (Python Flask + local Whisper)

## `transcribe_server/app.py`
```python
from flask import Flask, request, jsonify
import whisper, os, uuid, subprocess, pathlib

app = Flask(__name__)
MODEL_NAME = os.environ.get("WHISPER_MODEL", "small")
model = whisper.load_model(MODEL_NAME)

OUTDIR = pathlib.Path("output")
OUTDIR.mkdir(exist_ok=True)

def ensure_wav(input_path: str) -> str:
    p = pathlib.Path(input_path)
    if p.suffix.lower() == ".wav":
        return str(p)
    wav_path = OUTDIR / (p.stem + ".wav")
    subprocess.run(["ffmpeg", "-y", "-i", str(p), "-ac", "1", "-ar", "16000", str(wav_path)],
                   check=True, capture_output=True)
    return str(wav_path)

@app.post("/transcribe")
def transcribe():
    if "file" not in request.files:
        return jsonify(error="missing file field"), 400

    f = request.files["file"]
    ext = pathlib.Path(f.filename).suffix or ".wav"
    job_id = str(uuid.uuid4())
    raw_path = OUTDIR / f"{job_id}{ext}"
    f.save(raw_path)

    wav_path = ensure_wav(str(raw_path))

    prompt = (
        "This audio contains Tamil and English mixed speech. "
        "Preserve English technical terms exactly: API SQL server deployment invoice contract NDA VAT GST."
    )

    result = model.transcribe(
        wav_path,
        language="ta",
        task="translate",
        initial_prompt=prompt,
        beam_size=5,
        best_of=5,
        fp16=False
    )

    txt = result["text"].strip()
    txt_path = OUTDIR / f"{job_id}.txt"
    txt_path.write_text(txt, encoding="utf-8")

    return jsonify(job_id=job_id, text=txt)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5005)
```

import 'dart:convert';
import 'dart:io';
import 'package:flutter/material.dart';
import 'package:flutter_webrtc/flutter_webrtc.dart';
import 'package:http/http.dart' as http;
import 'package:path_provider/path_provider.dart';
import 'package:websocket_universal/websocket_universal.dart';

const SIGNALING_URL = "ws://YOUR_PC_IP:8080";      // e.g. ws://192.168.1.50:8080
const TRANSCRIBE_URL = "http://YOUR_PC_IP:5005/transcribe"; // e.g. http://192.168.1.50:5005/transcribe

void main() => runApp(const MaterialApp(home: Home()));

class Home extends StatefulWidget {
  const Home({super.key});
  @override State<Home> createState() => _HomeState();
}

class _HomeState extends State<Home> {
  final roomCtrl = TextEditingController(text: "room1");
  final _localRenderer = RTCVideoRenderer();
  final _remoteRenderer = RTCVideoRenderer();

  WebSocketController? ws;
  RTCPeerConnection? pc;
  MediaStream? localStream;

  bool inCall = false;
  String transcript = "";

  // audio recording
  String? recordPath;
  MediaRecorder? recorder;

  @override
  void initState() {
    super.initState();
    _localRenderer.initialize();
    _remoteRenderer.initialize();
  }

  @override
  void dispose() {
    _localRenderer.dispose();
    _remoteRenderer.dispose();
    roomCtrl.dispose();
    super.dispose();
  }

  Future<void> join() async {
    final roomId = roomCtrl.text.trim();
    if (roomId.isEmpty) return;

    ws = WebSocketController(
      WebSocketSimple.connect(Uri.parse(SIGNALING_URL)),
    );

    ws!.stream.listen((event) async {
      final msg = jsonDecode(event.toString());
      final type = msg["type"];
      final payload = msg["payload"];

      if (type == "offer") {
        await _ensurePeer();
        await pc!.setRemoteDescription(
          RTCSessionDescription(payload["sdp"], payload["type"]),
        );
        final answer = await pc!.createAnswer();
        await pc!.setLocalDescription(answer);
        _send("answer", {"type": answer.type, "sdp": answer.sdp});
      }

      if (type == "answer") {
        await pc!.setRemoteDescription(
          RTCSessionDescription(payload["sdp"], payload["type"]),
        );
      }

      if (type == "candidate") {
        await pc!.addCandidate(RTCIceCandidate(
          payload["candidate"], payload["sdpMid"], payload["sdpMLineIndex"],
        ));
      }
    });

    _send("join", {});
  }

  void _send(String type, Map<String, dynamic> payload) {
    final roomId = roomCtrl.text.trim();
    ws?.send(jsonEncode({"type": type, "roomId": roomId, "payload": payload}));
  }

  Future<void> _ensurePeer() async {
    if (pc != null) return;

    final config = {
      "iceServers": [
        {"urls": "stun:stun.l.google.com:19302"}
      ]
    };

    pc = await createPeerConnection(config);

    pc!.onIceCandidate = (c) {
      if (c.candidate != null) {
        _send("candidate", {
          "candidate": c.candidate,
          "sdpMid": c.sdpMid,
          "sdpMLineIndex": c.sdpMLineIndex
        });
      }
    };

    pc!.onTrack = (e) {
      if (e.streams.isNotEmpty) {
        _remoteRenderer.srcObject = e.streams[0];
      }
    };

    localStream = await navigator.mediaDevices.getUserMedia({
      "audio": true,
      "video": false
    });

    for (var t in localStream!.getTracks()) {
      await pc!.addTrack(t, localStream!);
    }

    setState(() {
      inCall = true;
      _localRenderer.srcObject = localStream;
    });

    await _startRecording();
  }

  Future<void> startCall() async {
    await _ensurePeer();
    final offer = await pc!.createOffer();
    await pc!.setLocalDescription(offer);
    _send("offer", {"type": offer.type, "sdp": offer.sdp});
  }

  Future<void> hangup() async {
    await _stopRecording();

    await pc?.close();
    pc = null;

    localStream?.getTracks().forEach((t) => t.stop());
    localStream = null;

    setState(() {
      inCall = false;
      _localRenderer.srcObject = null;
      _remoteRenderer.srcObject = null;
    });

    // upload recorded audio for transcription
    if (recordPath != null) {
      final t = await _uploadForTranscription(recordPath!);
      setState(() => transcript = t);
    }
  }

  Future<void> _startRecording() async {
    recorder = MediaRecorder();
    final dir = await getApplicationDocumentsDirectory();
    recordPath = "${dir.path}/call_audio.wav"; // flutter_webrtc may produce .wav/.aac depending platform
    await recorder!.start(
      recordPath!,
      audioChannel: RecorderAudioChannel.INPUT, // local mic; MVP per-device
    );
  }

  Future<void> _stopRecording() async {
    try { await recorder?.stop(); } catch (_) {}
    recorder = null;
  }

  Future<String> _uploadForTranscription(String path) async {
    final req = http.MultipartRequest("POST", Uri.parse(TRANSCRIBE_URL));
    req.files.add(await http.MultipartFile.fromPath("file", path));
    final resp = await req.send();
    final body = await resp.stream.bytesToString();
    if (resp.statusCode != 200) return "Transcribe failed: ${resp.statusCode}\n$body";
    final json = jsonDecode(body);
    return json["text"] ?? "(no text)";
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text("Call + Transcribe MVP")),
      body: Padding(
        padding: const EdgeInsets.all(12),
        child: Column(
          children: [
            TextField(controller: roomCtrl, decoration: const InputDecoration(labelText: "Room ID")),
            const SizedBox(height: 8),
            Row(
              children: [
                ElevatedButton(onPressed: join, child: const Text("Join Room")),
                const SizedBox(width: 8),
                ElevatedButton(onPressed: startCall, child: const Text("Start Call")),
                const SizedBox(width: 8),
                ElevatedButton(onPressed: hangup, child: const Text("Hangup + Transcribe")),
              ],
            ),
            const SizedBox(height: 12),
            Expanded(
              child: SingleChildScrollView(
                child: Text(transcript.isEmpty ? "Transcript will appear here." : transcript),
              ),
            )
          ],
        ),
      ),
    );
  }
}

## 🧭 STUN — “What is my public door number?”
**STUN = Session Traversal Utilities for NAT**

### What it actually does
- Your phone asks a STUN server:
  > “From the internet, what address do I look like?”
- STUN replies with:
  > “You appear as `203.0.113.45:54321`”

Now your phone knows its **public-facing address**.

### When STUN works
- Home Wi-Fi
- Simple routers
- Open networks

### When STUN fails
- Mobile data
- Corporate Wi-Fi
- Hotels / airports
- Symmetric NATs (very common)

📌 **STUN does NOT relay audio**  
It only helps devices **try** to connect directly.

---

## 🔁 TURN — “If you can’t reach each other, talk through me”
**TURN = Traversal Using Relays around NAT**

### What it actually does
- Phones give up on direct connection
- Both phones connect **outward** to a TURN server
- TURN **relays encrypted audio** between them

Think of TURN as a **secure telephone exchange**.

### Why TURN is critical
- Outbound connections are almost always allowed
- Firewalls don’t block it
- Works **internationally, everywhere**

📌 **TURN DOES carry audio**  
📌 **TURN costs bandwidth** (that’s why it’s not “free”)

## A3) Configure coturn (critical step)

Edit config:
```bash
sudo nano /etc/turnserver.conf
```

Paste **this minimal working config** (adjust values):

```ini
# --- Network ---
listening-port=3478
fingerprint
lt-cred-mech

# Replace with your server public IP
external-ip=YOUR_SERVER_IP

# --- Authentication ---
realm=turn.yourdomain.com
user=turnuser:turnpassword

# --- Security ---
no-loopback-peers
no-multicast-peers

# --- Performance ---
total-quota=100
bps-capacity=0
stale-nonce

# --- Logging ---
log-file=/var/log/turn.log
simple-log
```

Save & exit.
