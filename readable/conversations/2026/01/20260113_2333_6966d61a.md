In **Java**, there are **three standard ways** to write comments. Each has a specific purpose.

---

## 1️⃣ Single-line comment — `//`
Used for short explanations or inline notes.

```java
// This is a single-line comment
int x = 10; // Inline comment
```

✔ Everything after `//` on that line is ignored by the compiler.

---

## 2️⃣ Multi-line (block) comment — `/* ... */`
Used for longer explanations or temporarily disabling code.

```java
/* This is a multi-line comment
   It can span multiple lines */
int y = 20;
```

You can also comment out blocks of code:
```java
/*
int a = 5;
int b = 6;
System.out.println(a + b);
*/
```

---

## 3️⃣ Documentation comment (JavaDoc) — `/** ... */`
Used to generate **official API documentation** with the `javadoc` tool.

```java
/**
 * Adds two integers.
 *
 * @param a first number
 * @param b second number
 * @return sum of a and b
 */
public int add(int a, int b) {
    return a + b;
}
```

✔ This is **not just a comment** — it becomes part of Java’s generated docs.

---

## ⚠️ Things that do NOT work in Java
These are **not valid** in Java:
```java
# comment        // ❌ Python-style
-- comment       // ❌ SQL-style
<!-- comment --> // ❌ HTML-style
```

---

## ✅ Quick summary
| Purpose | Syntax |
|------|------|
| Single line | `// comment` |
| Multi-line | `/* comment */` |
| API docs | `/** comment */` |
