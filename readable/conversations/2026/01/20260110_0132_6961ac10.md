INSPIRATION FOR CATEGORIES:
Digital Loans - Loan agreements exist as complex long form legal documents, rather than as data. How can we apply technology to gather relevant data from these documents and represent that data in a structured digital form? How can we standardise the data gathered across the loan industry and facilitate interoperability between disparate systems, comparison between loans, querying and reporting.
Loan Documents - Loan agreements are typically complex long form documents running to many hundreds of pages. It takes a significant amount of time to accurately capture the commercial deal in the document, and negotiate the terms between the lender and the borrower. How could we speed up the creation and negotiation process? Or make it easier to spot inconsistencies when terms change last-minute?
Transparent Loan Trading - Lenders’ interests in loan agreements are bought and sold every day on the secondary loan market. For this to happen, certain procedural steps and due diligence need to be performed by the buyer of that interest. How might we automate due diligence checks that raise the cost of trades?
Keeping Loans on Track - Loan agreements set out a wide range of obligations on Borrowers, including adhering to various financial covenants, providing timely information and notifying other parties of specified events. These obligations can differ from one loan to the next. How can Borrowers and Lenders efficiently gather and distribute relevant information to ensure compliance with these requirements?
Greener Lending - Across the financial sector, there is growing demand for transparency and accountability around environmental, social and governance (ESG) performance. Lenders and borrowers are under pressure from investors, regulators and the public to demonstrate how capital is being used to support sustainable outcomes. However, ESG obligations and reporting requirements vary widely between loans, and data on performance is often fragmented, unverified, or difficult to compare. How might we make it easier to capture, verify and share ESG data across parties? Or help lenders factor sustainability into their decision-making?

## 8.11 Canon service (end-to-end orchestration)

### `service/CanonService.java`
```java
@Service
public class CanonService {
  private final TikaParser tika;
  private final RawDocumentRepo rawRepo;
  private final LoanVersionRepo verRepo;
  private final SchemaValidator schemaValidator;
  private final CanonRules rules;
  private final AiExtractor ai;
  private final ObjectMapper mapper = new ObjectMapper();

  public CanonService(...) { ... }

  public DocumentRef ingest(MultipartFile file) {
    String text = tika.parse(file);
    String hash = sha256(text);
    RawDocumentEntity doc = new RawDocumentEntity();
    doc.id = UUID.randomUUID();
    doc.filename = file.getOriginalFilename();
    doc.contentText = text;
    doc.sha256 = hash;
    rawRepo.save(doc);
    return new DocumentRef(doc.id, doc.filename, doc.sha256);
  }

  public CanonicalLoan extract(UUID docId) {
    RawDocumentEntity doc = rawRepo.findById(docId).orElseThrow();
    String json = ai.proposeCanonicalJson(doc.contentText, doc.sha256);
    schemaValidator.validate(json);
    CanonicalLoan loan = mapper.readValue(json, CanonicalLoan.class);
    rules.validate(loan);
    return loan;
  }

  public CanonicalLoan approve(UUID docId, String user) {
    RawDocumentEntity doc = rawRepo.findById(docId).orElseThrow();
    CanonicalLoan draft = extract(docId);

    UUID loanId = UUID.fromString(draft.loanId());
    int nextVersion = verRepo.findTopByLoanIdOrderByVersionNumDesc(loanId)
      .map(v -> v.versionNum + 1).orElse(1);

    CanonicalLoan approved = new CanonicalLoan(
      draft.loanId(),
      nextVersion,
      draft.economics(),
      draft.dates(),
      draft.parties(),
      draft.sources(),
      new CanonicalLoan.Audit(user, Instant.now(), doc.sha256)
    );

    LoanVersionEntity ent = new LoanVersionEntity();
    ent.id = UUID.randomUUID();
    ent.loanId = loanId;
    ent.versionNum = nextVersion;
    ent.canonicalJson = mapper.writeValueAsString(approved);
    ent.approvedBy = user;
    ent.approvedAt = approved.audit().approvedAt();
    ent.docHash = doc.sha256;
    verRepo.save(ent);
    return approved;
  }

  public LoanDiff diff(UUID loanId, int v1, int v2) {
    CanonicalLoan a = load(loanId, v1);
    CanonicalLoan b = load(loanId, v2);
    return LoanDiff.compare(a, b);
  }

  public CanonicalLoan load(UUID loanId, int version) {
    LoanVersionEntity ent = verRepo.findByLoanIdAndVersionNum(loanId, version).orElseThrow();
    try { return mapper.readValue(ent.canonicalJson, CanonicalLoan.class); }
    catch (Exception e) { throw new RuntimeException(e); }
  }

  private static String sha256(String s) { /* implement MessageDigest */ return ""; }
}
```

```java
    OpenAiResponse resp = client.post()
      .bodyValue(req)
      .retrieve()
      .bodyToMono(OpenAiResponse.class)
      .block(Duration.ofSeconds(20));
```

# 8) CODE-LEVEL DESIGN (JAVA / SPRING)

## Covenant Evaluation Engine

```java
@Service
public class CovenantEngine {

  public EvaluationResult evaluate(
      Covenant covenant,
      FinancialSubmission submission) {

    BigDecimal value = calculateMetric(
        covenant.definitionJson(), submission);

    boolean breached = switch (covenant.comparator()) {
      case "<=" -> value.compareTo(covenant.threshold()) > 0;
      case ">=" -> value.compareTo(covenant.threshold()) < 0;
      default -> throw new IllegalStateException();
    };

    return new EvaluationResult(
      covenant.id(),
      value,
      breached,
      Instant.now()
    );
  }
}
```

**Key point:**

- Deterministic, auditable

## 14) SCHEDULER & SLA ENGINE (ENTERPRISE RUNTIME)

### Why it exists
Obligations are **time-bound**. Banks require a **deterministic clock** that:
- advances obligation state
- enforces grace periods
- triggers notices
- records evidence

### States (authoritative)
```
PENDING → DUE → OVERDUE → (SATISFIED | BREACHED) → (CURED | WAIVED)
```

### Scheduler responsibilities
- Daily tick (idempotent)
- SLA evaluation
- State transitions
- Notification triggers
- Audit capture

### Code

```java
@Service
public class ObligationScheduler {

  private final ObligationRepo repo;
  private final AuditRepo audit;
  private final Clock clock;

  public ObligationScheduler(ObligationRepo repo, AuditRepo audit, Clock clock) {
    this.repo = repo;
    this.audit = audit;
    this.clock = clock;
  }

  @Scheduled(cron = "0 0 2 * * *") // daily 02:00
  public void runDaily() {
    LocalDate today = LocalDate.now(clock);

    repo.findActive().forEach(o -> {
      if (o.status().equals("PENDING") && today.isAfter(o.dueDate())) {
        o.status("OVERDUE");
        repo.save(o);
        audit.record("OBLIGATION_OVERDUE", o.id(), o.snapshot());
      }
    });
  }
}
```

**Enterprise note:** Uses `Clock` injection → testable time travel.

## 15) COVENANT DEFINITION DSL (NO HARD-CODING)

### Problem
Covenants differ per loan. Hard-coding logic is a dead end.

### Solution
A **small, deterministic DSL** stored as JSON and interpreted by the engine.

### Example: Leverage Covenant DSL
```json
{
  "metric": "NET_DEBT_TO_EBITDA",
  "formula": "(NET_DEBT) / (EBITDA)",
  "inputs": ["NET_DEBT", "EBITDA"],
  "threshold": 3.5,
  "comparator": "<=",
  "frequency": "QUARTERLY"
}
```

### Interpreter (safe, deterministic)

```java
@Component
public class CovenantDslInterpreter {

  public BigDecimal evaluate(String dslJson, FinancialSubmission fs) {
    // parse JSON
    // map inputs to fs values
    // compute formula deterministically
    // NO dynamic code execution
    return fs.netDebt().divide(fs.ebitda(), MathContext.DECIMAL64);
  }
}
```

## 17) COVENANT EVALUATION PIPELINE (END-TO-END)

```
Submission → DSL Evaluation → Threshold Check
           → Result → Breach/Cure Logic → Audit
```

### Code

```java
@Service
public class CovenantEvaluationService {

  private final CovenantRepo covRepo;
  private final CovenantDslInterpreter dsl;
  private final AuditRepo audit;

  public void evaluate(UUID loanId, FinancialSubmission fs) {
    covRepo.findByLoanId(loanId).forEach(c -> {
      BigDecimal value = dsl.evaluate(c.definitionJson(), fs);
      boolean breached = compare(value, c.threshold(), c.comparator());

      EvaluationResult r = new EvaluationResult(
        c.id(), fs.periodEnd(), value, breached
      );

      audit.record(
        breached ? "COVENANT_BREACH" : "COVENANT_OK",
        c.id(),
        r.toJson()
      );
    });
  }
}
```

### Consent Engine
```java
@Service
public class ConsentEngine {

  public ConsentAssessment assess(
      ConsentRule rule,
      LenderRoll roll,
      Map<UUID, ConsentStatus> received) {

    return switch (rule.consentType()) {
      case "NONE" -> ConsentAssessment.satisfied();
      case "AGENT_ONLY" ->
        received.containsKey(roll.agentId())
          ? ConsentAssessment.satisfied()
          : ConsentAssessment.required("Agent consent pending");
      case "MAJORITY_LENDERS" -> {
        int pct = roll.percentConsented(received.keySet());
        yield pct >= rule.thresholdPercent()
          ? ConsentAssessment.satisfied()
          : ConsentAssessment.required("Majority consent pending: " + pct + "%");
      }
      case "ALL_LENDERS" ->
        roll.allConsented(received.keySet())
          ? ConsentAssessment.satisfied()
          : ConsentAssessment.required("All lender consents required");
      default -> ConsentAssessment.required("Unsupported consent type");
    };
  }
}
```

**Explainability:** output always includes *why*.

## 17) TRADE READINESS SCORING (NOT AI, NOT OPINION)

### Purpose
Give desks a **single, explainable readiness outcome**.

### Readiness States
- `READY`
- `READY_WITH_CONDITIONS`
- `BLOCKED`

### Scoring Inputs

### Aggregator
```java
@Service
public class TradeReadinessAggregator {

  public TradeReadiness aggregate(List<Assessment> checks) {

    if (checks.stream().anyMatch(Assessment::isBlocked)) {
      return TradeReadiness.blocked(explain(checks));
    }

    if (checks.stream().anyMatch(Assessment::isRequired)) {
      return TradeReadiness.conditional(explain(checks));
    }

    return TradeReadiness.ready("All checks satisfied");
  }

  private String explain(List<Assessment> checks) {
    return checks.stream()
      .filter(a -> !a.isSatisfied())
      .map(Assessment::message)
      .collect(Collectors.joining("; "));
  }
}
```

**Key:** deterministic aggregation + human-readable explanation.

## 5.2 Consent Engine (threshold + workflow state)
```java
@Service
public class ConsentEngine {
  public Assessment assess(TransferRuleEntity rule, List<ConsentRequirementEntity> consents) {
    if ("NONE".equals(rule.consentType)) return Assessment.ok("No consents required", rule.sourceClauseRef);

    long received = consents.stream().filter(c -> "RECEIVED".equals(c.status)).count();
    long required = consents.stream().filter(c -> !"WAIVED".equals(c.status)).count();

    if ("ALL".equals(rule.consentType)) {
      return received == required
        ? Assessment.ok("All consents received", rule.sourceClauseRef)
        : Assessment.required("Pending consents: "+(required-received), rule.sourceClauseRef);
    }

    if ("MAJORITY".equals(rule.consentType)) {
      // In real system, weight by lender commitments; here use thresholdPercent + weighted roll.
      int pct = (int)Math.floor((received * 100.0) / Math.max(1, required));
      return pct >= rule.thresholdPercent
        ? Assessment.ok("Majority consents met: "+pct+"%", rule.sourceClauseRef)
        : Assessment.required("Majority consents pending: "+pct+"% < "+rule.thresholdPercent+"%", rule.sourceClauseRef);
    }

    return Assessment.required("Consent required: "+rule.consentType, rule.sourceClauseRef);
  }
}
```

## 5.6 Readiness Aggregator (single decision with explanation)
```java
@Service
public class ReadinessAggregator {
  public TradeReadiness aggregate(List<Assessment> checks) {
    if (checks.stream().anyMatch(Assessment::isBlocked))
      return TradeReadiness.blocked(explain(checks), checks);
    if (checks.stream().anyMatch(Assessment::isRequired))
      return TradeReadiness.conditional(explain(checks), checks);
    return TradeReadiness.ready("All checks satisfied", checks);
  }

  private String explain(List<Assessment> checks) {
    return checks.stream()
      .filter(a -> !a.isOk())
      .map(a -> a.level()+": "+a.message() + (a.sourceClauseRef()!=null ? " ["+a.sourceClauseRef()+"]" : ""))
      .reduce((a,b) -> a + "; " + b).orElse("OK");
  }
}
```

## 5.7 Trade Kernel Orchestrator (the heart)
```java
@Service
public class TradeKernelService {
  private final TradeRepo tradeRepo;
  private final TransferRuleRepo ruleRepo;
  private final ConsentRepo consentRepo;
  private final NoticeRepo noticeRepo;
  private final AuditService audit;
  private final TransferRulesEngine transfer;
  private final ConsentEngine consent;
  private final NoticeEngine notice;
  private final EligibilityEngine eligibility;
  private final BlockerEngine blockers;
  private final ReadinessAggregator aggregator;

  public TradeReadiness runReadiness(UUID tradeId, UserContext ctx) {
    ctx.require("TRADER_VIEW");

    TradeEntity t = tradeRepo.findById(tradeId).orElseThrow();
    TransferRuleEntity rule = ruleRepo.findByLoanId(t.loanId).orElseThrow();

    var consents = consentRepo.findByTradeId(tradeId);
    var notices  = noticeRepo.findByTradeId(tradeId);

    CovenantStatus cov = loadCovenantStatusFromProduct2(t.loanId);
    Counterparty buyer = loadBuyer(t.buyerId);

    List<Assessment> checks = List.of(
      transfer.assess(rule),
      eligibility.assess(buyer, rule),
      blockers.assess(cov),
      consent.assess(rule, consents),
      notice.assess(notices, Clock.systemUTC())
    );

    TradeReadiness readiness = aggregator.aggregate(checks);

    t.readinessStatus = readiness.status();
    t.readinessExplanation = readiness.explanation();
    t.updatedAt = Instant.now();
    tradeRepo.save(t);

    audit.record("READINESS_RUN", ctx.userId(), tradeId,
      "{\"status\":\""+t.readinessStatus+"\"}");

    return readiness;
  }
}
```

```java
public class EvidenceService {

  private final AuditRepo auditRepo;

  public EvidencePackEntity buildAndStore(UUID tradeId, UserContext ctx) {
    ctx.require("AUDIT_VIEW");

    EvidencePack pack = assemble(tradeId, ctx.userId());
    String json = toJson(pack);
    String hash = sha256(json);

    String prev = evidenceRepo.findTopHashByTradeId(tradeId).orElse(null);

    EvidencePackEntity ent = new EvidencePackEntity();
    ent.id = UUID.randomUUID();
    ent.tradeId = tradeId;
    ent.jsonPayload = json;
    ent.sha256 = hash;
    ent.prevHash = prev;
    ent.createdAt = Instant.now();
    evidenceRepo.save(ent);

    auditRepo.save(audit("EVIDENCE_EXPORTED", ctx.userId(), tradeId, "{\"hash\":\""+hash+"\"}"));
    return ent;
  }
}
```

### ConsentWeightingStrategy
```java

  int calculatePercent(List<LenderRollEntity> roll,
                       Set<UUID> consentedLenders);
```

### Commitment-Weighted Implementation
```java
@Component
public class CommitmentWeightedStrategy implements ConsentWeightingStrategy {

  @Override
  public int calculatePercent(List<LenderRollEntity> roll,
                              Set<UUID> consented) {

    BigDecimal total = roll.stream()
      .filter(LenderRollEntity::votingEligible)
      .map(r -> r.commitment)
      .reduce(BigDecimal.ZERO, BigDecimal::add);

    BigDecimal consentedAmt = roll.stream()
      .filter(r -> consented.contains(r.lenderId))
      .map(r -> r.commitment)
      .reduce(BigDecimal.ZERO, BigDecimal::add);

    if (total.signum() == 0) return 0;
    return consentedAmt.multiply(BigDecimal.valueOf(100))
      .divide(total, RoundingMode.FLOOR)
      .intValue();
  }
}
```

## 5.1 Obligation Scheduler (due/overdue)
Purpose: enforce dates and grace periods.

```java
@Service
public class EsgObligationScheduler {
  private final EsgObligationRepo repo;
  private final AuditService audit;
  private final Clock clock;

  @Scheduled(cron="0 0 2 * * *")
  public void tick() {
    LocalDate today = LocalDate.now(clock);
    for (var o : repo.findActive()) {
      if ("ACTIVE".equals(o.status)) {
        if (today.isEqual(o.dueDate)) {
          o.status = "DUE";
          repo.save(o);
          audit.record("ESG_OBLIGATION_DUE", "SYSTEM", o.obligationId, oToJson(o));
        } else if (today.isAfter(o.dueDate.plusDays(o.graceDays == null ? 0 : o.graceDays))) {
          o.status = "OVERDUE";
          repo.save(o);
          audit.record("ESG_OBLIGATION_OVERDUE", "SYSTEM", o.obligationId, oToJson(o));
        }
      }
    }
  }
}
```
