## Why the audio transcript is not working

### 1️⃣ **Session-level transcript limit (most common)**
Many live platforms (including IBM / Zoom / Webex / Teams–backed tools) cap **automatic transcription per session**:
- Either **max minutes** (e.g., 60–90 mins)
- Or **max continuous audio stream**
- Or **max transcript size (characters / tokens)**

When this happens:
- Audio continues ✔️
- Recording may continue ✔️
- **Transcript silently stops** ❌ (no error shown)

👉 This *exactly* matches your symptom.

---

### 2️⃣ **Speaker / language confidence drop**
If:
- Multiple speakers overlap
- Mixed accents + switching languages (English ↔ Tamil, etc.)
- Background noise increases

The engine may **auto-disable live transcription** because confidence drops below threshold.

Clue:
- Transcript works initially
- Then suddenly stops after active discussion

---

### 3️⃣ **Host / permission constraint**
Some platforms allow transcription only if:
- Host explicitly enabled it
- Or only for first N minutes
- Or only for certain participant roles

If the host joined late or reconnected, transcription can reset or die.

---

### 4️⃣ **Post-processing not triggered**
In some setups:
- **Live transcript ≠ final transcript**
- Final transcript is generated **after the session ends**

So during session:
- You see nothing
After session:
- Transcript appears (or partially appears)

---

## How to confirm *which one it is* (fast check)

Do **any one** of these:

1. Check session duration  
   - If >60–90 mins → **limit hit** almost guaranteed

2. Look at transcript timestamp  
   - Stops exactly at a round number (e.g., 60:00, 75:00) → **hard cap**

3. End the session → wait 10–30 mins  
   - If transcript appears later → **post-processing model**

---

## What to do *next time* (practical fixes)

Instead of 1 long session:
- 45–60 min blocks
- Restart session → transcript resets

### ✅ Option B: Parallel backup (recommended for hackathons)
- One device runs meeting
- One device records audio only (phone / local recorder)
- Upload later → manual transcript if needed

### ✅ Option C: Explicit host setting
Before starting:
- Confirm **“Live transcription enabled”**
- Confirm **“Save transcript after meeting”**
