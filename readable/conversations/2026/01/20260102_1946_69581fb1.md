## 3) Your confusion: File vs Database vs LLM (clean difference)

### Files (hard disk truth)
- **What:** raw text, markdown, json, html, excel files stored on disk  
- **Strength:** transparent, portable, readable forever  
- **Role here:** **ground truth memory** (what actually happened)

### Database (structured truth)
- **What:** organized storage (SQLite/DuckDB) with tables/queries  
- **Strength:** fast filters, joins, deduping, tracking versions  
- **Role here:** **index + control plane** (how to find/organize memory)

> A DB still lives on disk (it’s a file too), but behaves like a queryable system.

### LLM (reasoning engine, not memory)
- **What:** a probabilistic text generator that can summarize, infer, transform  
- **Strength:** interpretation, synthesis, extraction, natural language querying  
- **Role here:** **compute over your memory**, not store it

**Blunt rule:**  
- Files/DB = **truth store**  
- LLM = **assistant brain** (useful, but not authoritative)
