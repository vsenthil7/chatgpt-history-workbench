# 5. But **session history is not context**

This distinction is critical.

`session.md + input.md + response.md` answer:

> **What happened?**

`CURRENT_CONTEXT.md` answers:

> **What does the next AI need to know NOW to continue correctly?**

Therefore **every turn must inspect whether context changed**.

If it did:

```text
context/CURRENT_CONTEXT.md
```

gets updated in the **same Git turn**.
