### Python script for your Windows machine

This uses **FFmpeg through Python**. Put the script in the same folder as your `.ogg`, `.aac`, `.mp3`, etc.

```python
import subprocess
from pathlib import Path

# ===== CHANGE THESE =====
INPUT_FILE = r"my_audio.ogg"
MAX_MINUTES_PER_PART = 30
# ========================

input_path = Path(INPUT_FILE)
output_dir = input_path.parent / f"{input_path.stem}_wav_parts"
output_dir.mkdir(exist_ok=True)

# Get duration
result = subprocess.run(
    [
        "ffprobe",
        "-v", "error",
        "-show_entries", "format=duration",
        "-of", "default=noprint_wrappers=1:nokey=1",
        str(input_path),
    ],
    capture_output=True,
    text=True,
    check=True,
)

duration = float(result.stdout.strip())
part_seconds = MAX_MINUTES_PER_PART * 60

start = 0
part = 1

while start < duration:
    output_file = output_dir / f"{input_path.stem}_part_{part:02d}.wav"

    command = [
        "ffmpeg",
        "-y",
        "-ss", str(start),
        "-i", str(input_path),
        "-t", str(part_seconds),

        # Transcription-friendly WAV
        "-ac", "1",             # Mono
        "-ar", "16000",         # 16 kHz
        "-c:a", "pcm_s16le",    # 16-bit PCM WAV

        str(output_file),
    ]

    print(f"\nCreating: {output_file.name}")
    subprocess.run(command, check=True)

    size_mb = output_file.stat().st_size / 1_000_000
    print(f"Size: {size_mb:.1f} MB")

    start += part_seconds
    part += 1

print("\nDONE")
print(f"Files saved to: {output_dir}")
```

Run:

```powershell
python convert_audio.py
```

### Why I suggest **30-minute chunks**

At **16 kHz mono PCM**, WAV consumes about **1.92 MB/minute**. So:

- 30 min ≈ **58 MB**
- 40 min ≈ **77 MB**
- 50 min ≈ **96 MB**

Therefore, **30-minute chunks are a safe default** when a transcription service has a 100 MB upload limit.

You only need to install **FFmpeg once** and have `ffmpeg` + `ffprobe` available on your Windows PATH.
