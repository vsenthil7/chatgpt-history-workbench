### Most important: speaker split

This directly answers the issue you raised earlier about Sarvam showing different speakers.

Speaker diarization is available in the **Batch API**:

```python
with_diarization=True
```

Optionally:

```python
num_speakers=2
```

If we don't specify `num_speakers`, Sarvam can automatically detect the number of speakers. It supports up to **20 speakers**. citeturn0search10

So for your Rivin/Subha/meeting recordings, we should enable diarization by default.

### We don't necessarily need WAV conversion

This changes my previous design.

Sarvam already accepts:

**WAV, MP3, AAC, AIFF, OGG, OPUS, FLAC, MP4/M4A, AMR, WMA and WebM.** citeturn0search0turn0search1

Therefore, taking:

```text

        ↓
convert to huge WAV
        ↓
split WAV
        ↓
Sarvam
```

is often **unnecessary work**.

For a valid `.ogg`, `.aac`, `.mp3`, etc., we should normally send the original compressed audio directly.

For video, Sarvam even supports MP4/WebM, although I'd still prefer extracting audio first because it reduces upload size and gives us a clean audio audit artifact.

### Another important correction: duration matters more

Sarvam has two very different STT APIs:

```text
SHORT AUDIO ≤ 30 sec
        ↓
REST /speech-to-text
        ↓
immediate result


LONG AUDIO ≤ 2 hours
        ↓
BATCH API
        ↓
upload → process → wait → download result
```

The ordinary REST endpoint has a **30-second maximum**. Batch handles **up to two hours per file**. citeturn0search7turn0search9

So our script should make the API decision based primarily on **duration**, not just MB.

# 7. What happens first

It does **not immediately convert the whole OGG to WAV**.

It first inspects:

```text
Container
Codec
Duration
File size
Sample rate
Channels
Audio/video
```

Then it makes approximately a **20-second OGG test file** and sends that small file to Sarvam REST.

Sarvam documents REST for recordings under 30 seconds and officially lists OGG among its supported formats. citeturn0search0

You'll see something like:

```text

      Test file : original_format_test.ogg

```

### If OGG works

It reports:

```text
PASS: Sarvam returned a non-empty transcript.

Keeping source format; full WAV conversion NOT required.
```

Therefore:

**OGG → OGG → Sarvam**

No unnecessary WAV.
