## 4. Track-wise enterprise ideas

### Track 1 — GTM Intelligence  
## Idea: **SignalForge GTM**

An always-on revenue intelligence agent that monitors competitors, pricing pages, hiring, product launches, review sites, LinkedIn/company pages, and SERP changes.

**Enterprise users:** Sales, marketing, RevOps, product marketing.  
**Output:** Battlecards, CRM enrichment, competitor change alerts, account briefs.

**Bright Data use:**
- SERP API for discovery
- Web Scraper API for structured company/product data
- Web Unlocker for blocked public pages
- MCP Server for agent workflow

---

### Track 2 — Finance & Market Intelligence  
## Idea: **VendorPulse RiskGraph**

A live supplier/vendor intelligence system that tracks public web signals: layoffs, leadership exits, lawsuits, pricing changes, financial stress, regulatory filings, reviews, hiring freezes, and market sentiment.

**Enterprise users:** Procurement, finance, risk, supply-chain, CFO office.  
**Output:** Vendor risk score, watchlist, change alerts, evidence pack.

**Bright Data use:**
- SERP API for broad monitoring
- Scraping Browser for complex public pages
- Web Scraper API for structured company/job/product data
- Web Unlocker for reliable access

---

### Track 3 — Security & Compliance  
## Idea: **OpenRisk Sentinel**

An AI agent that monitors open web sources for company-specific risk: leaked brand mentions, phishing domains, impersonation pages, fake job posts, regulatory changes, public breach chatter, and vendor compliance risk.

**Enterprise users:** Security, compliance, legal, third-party risk teams.  
**Output:** Risk alert, source evidence, severity score, recommended action.

**Bright Data use:**
- SERP API for discovery
- Web Unlocker for access
- Scraping Browser for interactive sites
- MCP Server for autonomous investigation
