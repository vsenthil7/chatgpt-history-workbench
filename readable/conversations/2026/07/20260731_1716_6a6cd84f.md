I had a look through the workbook structure. Overall, I think the problem is **not Excel**. It is the **data model**. This design will become increasingly difficult in Google Sheets as the number of employees and tasks grows.

### Major Problems I Found

| # | Problem | Effect | Solution |
|---|---------|--------|----------|
| 1 | **Same information exists in multiple sheets** (Daily Planner, Daily Tracker, Overall Planner) | Triple data entry, inconsistencies | Keep **one Master Task table** and generate views automatically. |
| 2 | **Google Sheets will become slow** | Multiple large sheets with duplicated records | Store everything in one database-style table. |
| 3 | **Unused columns up to AB** | Bigger workbook, unnecessary scrolling | Remove unused columns. |
| 4 | **Mixed data types** (`NIL`, `Nil`, `NIl`, text time like `2.30Pm`) | Formulas, sorting and reporting break | Use real Date/Time values and leave blanks instead of text. |
| 5 | **No Task ID** | Impossible to relate planner, tracker and timesheet | Add unique Task ID (e.g. TSK-000001). |
| 6 | **Planner and Tracker contain almost the same data** | Double maintenance | Planner should create the task. Tracker should only update execution. |
| 7 | **Status is free text** | Reports become unreliable | Use dropdowns (Not Started, In Progress, Blocked, Completed, Cancelled). |
| 8 | **Priority is not standardised** | Difficult filtering | Dropdown only (High, Medium, Low). |
| 9 | **Timesheet isn't linked to tasks** | Cannot measure productivity | Every work entry should reference a Task ID. |
|10| **Employee information exists only in Timesheet** | Won't scale to multiple employees | Every task should have an Owner column. |
|11| **No KPI dashboard** | Management cannot monitor progress | Build Pivot Tables / Dashboard. |
|12| **Manual duplication everywhere** | Human error | Use lookup/formulas or Power Query instead of copying data. |
