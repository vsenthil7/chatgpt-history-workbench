# 3. SSO (Single Sign-On)

This is the main point.

SSO means:

```
Company Login
      │
      ▼
Microsoft Entra ID
or
Google Workspace
      │
      ▼
ChatGPT
GitHub
Slack
Jira
Figma
Dropbox
...
```

Instead of every employee having a separate password for every service, they all sign in using the company's identity provider.

For example:

```
subha@omshakthi.co.uk
        │
        ▼
Microsoft Entra ID
        │
        ▼
ChatGPT Business
GitHub
Jira
Slack
Zoom
```

One login.

---

# 4. Why doesn't Gmail work for SSO?

Because **Gmail is an individual consumer account**.

For example:

```
omshakthi@gmail.com
```

is just one Google account.

It is **not** an identity provider that manages employees.

Google Workspace is different.

Example:

```
Google Workspace

admin@company.com

creates

subha@company.com
hr@company.com
support@company.com
finance@company.com
```

Now Google Workspace knows:

- who works for the company
- who left
- who is an admin
- who belongs to HR

ChatGPT Business can trust that identity.

---

# 5. Microsoft is similar

Microsoft 365 Business uses:

```
Microsoft Entra ID
```

formerly Azure Active Directory.

So:

```
subha@company.com
```

logs into:

- Teams
- Outlook
- SharePoint
- ChatGPT
- GitHub

using the same identity.

---

# 6. Can Gmail still use ChatGPT Business?

**Absolutely.**

There is **nothing stopping you** from doing:

```
Owner

omshakthi@gmail.com
```

Many startups do exactly this.

---

# 7. Can Gmail use Microsoft Authenticator?

Yes.

You can enable **multi-factor authentication (MFA)** on a Gmail account and even use Microsoft Authenticator (or other compatible authenticator apps) to generate verification codes.

That's different from SSO.

Think of it this way:

```
Gmail
  +
Microsoft Authenticator

= More secure login
```

whereas

```
Microsoft Entra ID

= Company identity system
```

Those are different concepts.

---

You can start with a simple account and later move to centralized identity and access management as your organization grows.

ChatGPT Business is much the same: you can start with a Gmail owner and later adopt company-managed identities if and when your IT environment requires them.
