```md
2) System must generate a Deadlock Notice:
   snapshots/YYYY-Wxx/Deadlock_Notice.md
3) System must propose ONE of the allowed resolution paths (non-binding):
   - Defer with expiry (new deadline)
   - Narrow scope (partial decision that is safe)
   - Assign third-party arbitrator
   - Convert to “Experiment proposal” with capped risk/time

## Forbidden
- System must not “decide by timeout”.
- System must not pick between anchors.
```

# 3) Tamper-evident hashes for snapshots

This makes snapshots **detectably immutable**, even if files are edited later.

## 3.1 Snapshot hash manifest (per snapshot)
For every `snapshots/YYYY-Wxx/`, create:

- `hash_manifest.sha256` (hashes of each artifact file)
- `hash_chain.txt` (links this snapshot to previous snapshot)

### Manifest format
```text
<sha256>  Weekly_Snapshot.md
<sha256>  Open_Loops.md
<sha256>  Drift_Report.md
<sha256>  input_index.md
<sha256>  Escalation_Packet.md
<sha256>  override_log.md
```

### Chain format (simple + effective)
```text
prev_snapshot_id: YYYY-Wxx-1
prev_chain_hash: <sha256 of previous hash_chain.txt>
current_manifest_hash: <sha256 of current hash_manifest.sha256>
current_chain_hash: <sha256 of (prev_chain_hash + current_manifest_hash + snapshot_id)>
```

## 3.2 Workflow enforcement (add to end of workflow)
```text
TAMPER-EVIDENT HASHING (required)

After generating snapshot artifacts:
1) Compute SHA-256 for each required artifact file in snapshots/YYYY-Wxx/
2) Write snapshots/YYYY-Wxx/hash_manifest.sha256
3) Compute current_manifest_hash = SHA-256(hash_manifest.sha256)
4) Load previous snapshot’s hash_chain.txt (if exists) to get prev_chain_hash
5) Write snapshots/YYYY-Wxx/hash_chain.txt linking prev_chain_hash → current_manifest_hash
6) Record both hashes at the top of Weekly_Snapshot.md
```

## 3.3 Minimal script (portable) — Bash
Put in `tools/hash_snapshot.sh` (optional):

```bash
#!/usr/bin/env bash
set -euo pipefail

SNAP_DIR="$1"          # e.g., snapshots/2026-W06
PREV_DIR="${2:-}"      # e.g., snapshots/2026-W05

cd "$SNAP_DIR"

# Create manifest for key artifacts (edit list as needed)
FILES=(
  "Weekly_Snapshot.md"
  "Open_Loops.md"
  "Drift_Report.md"
  "input_index.md"
  "override_log.md"
)
# Add optional files if present
[ -f "Escalation_Packet.md" ] && FILES+=("Escalation_Packet.md")
[ -f "Conflict_Report.md" ] && FILES+=("Conflict_Report.md")
[ -f "Weekly_Snapshot_RESTRICTED.md" ] && FILES+=("Weekly_Snapshot_RESTRICTED.md")
[ -f "Arbitration_Packet.md" ] && FILES+=("Arbitration_Packet.md")

: > hash_manifest.sha256
for f in "${FILES[@]}"; do
  sha256sum "$f" >> hash_manifest.sha256
done

MANIFEST_HASH=$(sha256sum hash_manifest.sha256 | awk '{print $1}')

PREV_CHAIN_HASH="GENESIS"
if [ -n "$PREV_DIR" ] && [ -f "../$(basename "$PREV_DIR")/hash_chain.txt" ]; then
  PREV_CHAIN_HASH=$(sha256sum "../$(basename "$PREV_DIR")/hash_chain.txt" | awk '{print $1}')
fi

SNAP_ID=$(basename "$SNAP_DIR")
CHAIN_MATERIAL="${PREV_CHAIN_HASH}${MANIFEST_HASH}${SNAP_ID}"
CURRENT_CHAIN_HASH=$(printf "%s" "$CHAIN_MATERIAL" | sha256sum | awk '{print $1}')

cat > hash_chain.txt <<EOF
prev_snapshot_id: ${PREV_DIR##*/}
prev_chain_hash: ${PREV_CHAIN_HASH}
current_manifest_hash: ${MANIFEST_HASH}
current_chain_hash: ${CURRENT_CHAIN_HASH}
EOF

echo "OK: $SNAP_ID"
echo "manifest_hash=$MANIFEST_HASH"
echo "chain_hash=$CURRENT_CHAIN_HASH"
```

This is enough for tamper evidence: if anyone edits a past snapshot, hashes won’t match downstream.
