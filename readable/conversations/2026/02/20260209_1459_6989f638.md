- Teaching / mentoring sessions

- ❌ Not a production server  
- ❌ Not persistent storage (runtime resets)  
- ❌ Not enterprise-grade governance by default

- Session is **temporary** (disconnects after inactivity or max hours)
- Files vanish unless saved to:
  - Google Drive
  - GitHub
  - Downloaded manually

- You want to **test ideas fast**
- You need **GPU now**, not after setup
- You’re teaching / explaining code live
- You’re comparing models or approaches quickly

### When it’s the wrong tool
- Long-running services
- Compliance / audit-heavy work
- Deterministic, reproducible pipelines without extra tooling
- Anything requiring strict environment control

entity["organization","Google Colaboratory","cloud notebook service"] works in **two different “save modes”**, and people often mix them up.

---

## What gets saved when you log in

### ✅ The notebook file **can be saved**
If you **explicitly save** the notebook:
- **File → Save a copy in Drive**
- or **File → Save**

➡️ The **`.ipynb` file is stored permanently** in your **Google Drive**.

You can close the browser, shut down your laptop, come back next week — the **notebook file is still there**.

---

## What does NOT get saved automatically

### ❌ The running environment
These are **NOT saved**:
- Installed libraries (`pip install ...`)
- Uploaded files (CSV, images, zips)
- Variables in memory
- Running state of cells
- Downloaded models

When the session ends:
➡️ **Runtime resets to zero**

Think of it like:
> Notebook = Google Doc (saved)  
> Runtime = rented computer (temporary)

---

## Safe mental model (very important)
- **Login ≠ auto-save everything**
- **Save notebook ≠ save runtime**
- **Runtime reset ≠ notebook deleted**

---

## How to make work persistent (basic options)

### Option 1: Save to Google Drive (most common)
```python
from google.colab import drive
drive.mount('/content/drive')
```
- Store data, models, outputs in Drive
- Survives runtime resets

### Option 2: Push to GitHub
- Save `.ipynb`
- Commit code + outputs you care about
- Best for versioning & audits

### Option 3: Re-run cells deterministically
- Put all installs at the top:
```python
!pip install torch pandas numpy
```
- Makes reset painless

---

## One-line truth
> **Logging in saves the notebook file only if you save it — the compute state is always temporary.**
