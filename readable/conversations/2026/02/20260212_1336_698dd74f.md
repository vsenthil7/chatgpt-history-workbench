## Python — Palindrome Check (Reverse String Method)

A **palindrome** is a string that reads the same forward and backward.  
Example: `madam`, `racecar`, `121`.

Let’s build this step by step.

---

## 1️⃣ Basic Version (Case-Sensitive)

**Estimated time: 5 minutes**

```python
def is_palindrome(text):
    return text == text[::-1]

# Test
word = input("Enter a word: ")
if is_palindrome(word):
    print("Palindrome ✅")
else:
    print("Not a palindrome ❌")
```

### How it works:
- `text[::-1]` → reverses the string using slicing
- Compare original with reversed

---

## 2️⃣ Case-Insensitive Version

**Estimated time: 5 minutes**

```python
def is_palindrome(text):
    text = text.lower()
    return text == text[::-1]

print(is_palindrome("Madam"))  # True
```

---

## 3️⃣ Ignore Spaces & Special Characters (Real-World Version)

**Estimated time: 10–15 minutes**

This handles sentences like:
> "A man, a plan, a canal: Panama"

```python
import re

def is_palindrome(text):
    # Remove non-alphanumeric characters
    cleaned = re.sub(r'[^A-Za-z0-9]', '', text).lower()
    return cleaned == cleaned[::-1]

print(is_palindrome("A man, a plan, a canal: Panama"))  # True
```

---

## 4️⃣ Manual Reverse (Without Slicing)

If interviewer says:
> "Don't use slicing"

```python
def is_palindrome(text):
    reversed_text = ""
    for char in text:
        reversed_text = char + reversed_text
    return text == reversed_text
```

---

## 5️⃣ Using Two-Pointer Method (Best for Interviews)

**Estimated time: 10 minutes**

```python
def is_palindrome(text):
    left = 0
    right = len(text) - 1
    
    while left < right:
        if text[left] != text[right]:
            return False
        left += 1
        right -= 1
    
    return True
```

This avoids creating a new string → memory efficient.
