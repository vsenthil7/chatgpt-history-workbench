# ✅ STEP 1 — Check Real-Time Disk Usage (Process Level)

Open **PowerShell as Administrator**

### Show top disk writers (live snapshot)

```powershell
Get-Process | Sort-Object -Descending IO | Select-Object -First 15 Name, Id, CPU, @{Name="IO_MB";Expression={[math]::Round($_.IO/1MB,2)}}
```

This shows which processes have high IO.

---

### Better: Real Disk Write per Second (more accurate)

```powershell
Get-Counter '\Process(*)\IO Write Bytes/sec' |
Select-Object -ExpandProperty CounterSamples |
Sort-Object CookedValue -Descending |
Select-Object -First 15 |
Format-Table InstanceName, CookedValue
```

This shows which process is actively writing.

---

# ✅ STEP 2 — Check Disk Space Growth

```powershell
Get-PSDrive -PSProvider FileSystem
```

Look at Used / Free space.

---

# ✅ STEP 3 — Find Large Folders Quickly

This will scan C drive and show top folders.

⚠ This takes time.

```powershell
Get-ChildItem C:\ -Directory -Recurse -ErrorAction SilentlyContinue |
ForEach-Object {
    $size = (Get-ChildItem $_.FullName -Recurse -ErrorAction SilentlyContinue | Measure-Object -Property Length -Sum).Sum
    [PSCustomObject]@{
        Folder = $_.FullName
        SizeGB = [math]::Round($size / 1GB, 2)
    }
} | Sort-Object SizeGB -Descending | Select-Object -First 20
```
