Alright partner, let’s strip this down clean and scientific — but with a tiny bit of awe because light is kinda magical.

### 🌈 First: What RGB actually means
RGB = **Red, Green, Blue**  
It’s an **additive color model** — meaning we *add light* to create colors.

Each channel usually ranges from **0 to 255**:

- 0 = no light  
- 255 = full intensity  

---

## ⚫ How BLACK is created

In RGB:

```
R = 0
G = 0
B = 0
```

So:

**RGB(0, 0, 0) → Black**

Why?  
Because **no light is emitted**.  
Your screen pixels are simply off.

Black = absence of light.

---

## ⚪ How WHITE is created

In RGB:

```
R = 255
G = 255
B = 255
```

So:

**RGB(255, 255, 255) → White**

Why?  
Because **all three colors are emitted at full intensity**.

When red + green + blue light combine at maximum brightness, your eyes perceive it as white.

White = full light.

---

### 🧠 Important Concept: Additive Mixing

RGB is used in:
- Screens (phones, laptops, TVs)
- LEDs
- Digital graphics

Because screens emit light.

This is different from paint mixing (which is subtractive — CMYK).

---

### Quick Intensity Table

| Color | R | G | B |
|-------|---|---|---|
| Black | 0 | 0 | 0 |
| White | 255 | 255 | 255 |
| Red | 255 | 0 | 0 |
| Green | 0 | 255 | 0 |
| Blue | 0 | 0 | 255 |
| Gray (mid) | 128 | 128 | 128 |

Gray happens when all three are equal but not max.

That’s the entire visible digital world compressed into 3 numbers.
