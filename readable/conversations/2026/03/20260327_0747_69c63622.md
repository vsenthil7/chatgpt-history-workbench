## 🧱 1. Core Entities (Minimum Viable COS)

We start **very strict and minimal**.

### 🔹 1. Project

Represents a **container of intent**

**Fields:**

- `project_id` → unique (AT-…)
- `project_name`
- `domain` → (Mentoring / Trust / WE MD / Product / Personal)
- `status` → Active / Paused / Archived
- `created_date`
- `last_activity_date`
- `owner`

---

### 🔹 2. Page

Represents a **unit of work / thinking / execution**

**Fields:**

- `page_id`
- `project_id` (link)
- `page_name`
- `page_type` → (Input / Processing / Analysis / Decision / Log)
- `state` → (very important — see below)
- `source_type` → (WA / Call / Manual / System)
- `created_date`
- `last_updated`

---

### 🔹 3. Task

Represents **actionable work extracted from pages**

**Fields:**

- `task_id`
- `page_id`
- `description`
- `status`
- `priority`
- `assigned_to`
- `due_date`
- `origin` → (AI / User / Derived)

---

## ⚙️ 2. State System (THIS IS THE HEART)

This is where COS becomes “intelligent”.

### 🔹 Page State Model

```
RAW → PROCESSED → INTERPRETED → ACTIONED → CLOSED
```

**Meaning:**

| State        | Meaning |
|--------------|--------|
| RAW          | Input exists but not structured |
| PROCESSED    | Converted into structured form (Excel / SheetSync) |
| INTERPRETED  | Insights extracted |
| ACTIONED     | Tasks created / decisions taken |
| CLOSED       | Fully complete |

---

### 🔹 Task State Model

```
NOT_STARTED → IN_PROGRESS → BLOCKED → DONE
```

---

### 🔹 Project State (Derived, NOT manual)

Project state should be:

- AUTO-calculated based on pages + tasks

Example:

- If many pages in RAW → project = “Unstructured”
- If tasks pending → “Active”
- If no activity → “Dormant”
