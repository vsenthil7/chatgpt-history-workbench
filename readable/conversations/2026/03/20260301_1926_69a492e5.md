Horizontal scaling is **query-level parallelism**, not **intra-query parallelism**.

---

# 3️⃣ Why Not Split One Query Across Multiple Clusters?

Because distributed query coordination across independent clusters would:

- Increase network shuffle cost
- Increase synchronization overhead
- Increase merge complexity
- Add cross-cluster latency
- Reduce determinism

In distributed systems:

More nodes ≠ always faster.

There is a point where coordination cost > compute gain.

So Snowflake design choice:

> Keep single-query execution inside one tightly coupled cluster  
> Use additional clusters only for additional queries

Architecturally cleaner. Predictable performance.

---

# 4️⃣ Where Data Parallelism Actually Lives

Data parallelism happens:

✔ Across nodes within one cluster  
✔ Across CPU cores within nodes  
✔ Across micro-partitions  

Horizontal scaling adds:

✔ Parallel clusters  
❌ Not parallel fragments of same query  

---

# 5️⃣ Analogy (Precise One)

Think of:

Cluster = One factory  
Nodes = Workers in factory  

Vertical scaling = Hire more workers inside same factory  
Horizontal scaling = Open another factory  

If one car is being assembled:
- Adding workers in same factory helps
- Opening another factory does nothing for that car

It helps only when building multiple cars.

---

# 6️⃣ When Would Horizontal Help Single Query?

Only if:

- Query is so large it exceeds max cluster size
- System supports cross-cluster distributed execution
- Architecture supports global shuffle coordination

Snowflake intentionally does NOT do this.

# 7️⃣ Deep Architectural Reason (The Real Answer)

Snowflake separates:

- Storage (shared, immutable micro-partitions)
- Compute (isolated warehouses)

Warehouses are designed to be:

✔ Independent  
✔ Stateless  
✔ Isolated  

If a single query were split across clusters:

- Warehouses would need shared state
- Cross-cluster synchronization layer required
- Isolation guarantee weakens
- Cost model becomes unpredictable

Snowflake chooses:

> Isolation over cross-cluster speed scaling

Horizontal scaling does not improve single-query performance because:

- Data parallelism already exists inside one cluster
- Multi-cluster scaling is for concurrency, not intra-query distribution
- Cross-cluster coordination cost would outweigh benefit
- Snowflake architecture prioritizes isolation and predictability
