1 · Context

MeetSync is a Zoom Marketplace app for sales teams. A meeting ends; Zoom produces a transcript; MeetSync reads it, pulls out the commitments and the risk signals, and writes agreed fields into the CRM the customer already uses — under per-field rules the customer sets, with a review step, a queue that survives a crash and an audit row for every write.

The engineering has been unusually disciplined and the product has never been installed by a stranger. Both are true at once, and this document exists so the gap between them is visible at a glance. On 16 September an external reviewer read the code and then checked the claims made around it, raising fourteen findings — three of them critical. Code v0.45.0 is the response. The colouring below is the honest state after that response.

7 · What is complete, and what is not — with the reason

Capability status at code v0.45.0. "Reachable" means a customer can invoke it through a route the typed client calls; it is machine-enforced by two standing gates.
CapabilityStatusWhy it is where it is
Install & tenancyCompleteWorkspace identity comes from Zoom, not the caller; a disagreeing hint is refused with an audit row. The takeover path found on 16 September is closed and pinned by two named regression tests.
Sessions & access controlCompleteReal Zoom user and role, sixty-minute life, revocable individually or per workspace, delivered in an HttpOnly cookie. Owner/admin/member matrix with every decision — including denials — audit-logged.
HTTP hardeningCompleteCSP that admits the Zoom iframe, explicit CORS allowlist, 256 KB body cap, token-bucket limits per IP, per account and for the operator surface. Written without dependencies so it cannot drift with a transitive upgrade.
DurabilityCompleteNine PostgreSQL stores, each run through one contract suite twice — once in memory, once against a live database that CI refuses to skip. Tokens encrypted at rest; a purge is a real DELETE.
F1 Live notesCompleteDurable since v0.45.0. It was the least durable thing in the product and the only thing a human typed by hand — a deploy during business hours used to discard every in-flight session.
F3 CRM writeback engineCompleteField mapping with per-field overwrite policy, a queue that survives a crash, retry with jitter, an audit row per write, and a human review step before anything is sent. This is the defensible part of the product.
Web panelBuilt, unverifiedEvery panel now reads and writes through the API — it was a mock until v0.45.0. It has still never rendered inside the Zoom client; jsdom cannot judge colour contrast or screen-reader behaviour in a webview. Needs a live install.
F2 Action extractionBuilt, thinA five-phrase substring matcher. It works, it is honest, and it is worse than the free summariser Zoom now bundles. Whether it becomes a model or stays a rules engine is decision PD-02.
BillingBuilt, no moneyTrials, plans, proration, seat prompts, cancellation and entitlement enforcement all work. No payment processor exists, so no money has ever moved. Needs PD-01 then ST-137.
F4 Deal riskHeldThirteen hardcoded English keywords with no confidence score, unable to fire on the Hindi and Tamil calls the product is positioned for. Shipping it badly is worse than not shipping it — decision PD-04: rebuild inside real extraction, or cut it from the product and the pricing table.
F5 Indic packNot builtThere is a word-error-rate ruler and nothing to measure with it: no speech recognition exists anywhere in the codebase. This is simultaneously the most defensible claim MeetSync could make and the least built thing in it. PD-02, then a consented corpus of real calls.
Intelligence (LLM/ASR)Not builtNo model, no inference, no embeddings — the review searched fifty-nine files and found the word "speech" inside one comment. The listing copy promising transcription is held behind a banner that the build gate enforces, so it cannot be submitted over code that does not back it.
Live CRM connectionNot builtThree sandbox adapters, zero live OAuth, zero real writes. Needs HubSpot / Salesforce / Zoho sandbox credentials — the one item here blocked purely on access rather than on a decision.
Data residencyNot enforcedThe region setting is a label that is validated at boot and then only echoed. Rather than leave the claim standing, v0.45.0 removed it: /trust now reports regionEnforced: false and the page lists residency under "Not yet".
SSO · SOC 2 · pen testNot builtAn enterprise security questionnaire stops at question one. SOC 2 Type II is a funded programme — roughly $35K–$120K over six to eighteen months — not a sprint. Whether it starts now is decision PD-03.
Demand evidenceNoneZero installs. Zero paying customers. Zero users outside the build. 712 passing tests say the code does what it claims; they say nothing about whether anyone wants it. Three falsifiable demand tests are specified and unrun — PD-06.

The one-sentence version. MeetSync has a platform most funded startups would envy wrapped around a feature set that is mostly keyword matching, and it has never met a customer. Everything an engineer can fix alone has been fixed; what remains needs four decisions, one set of credentials, and ten strangers willing to pay.

8 · Evidence behind the colouring

ClaimHow it is enforced
"Built and tested"712 tests across 40 suites; 100% statements, branches, functions and lines; zero coverage pragmas; TypeScript strict. CI fails below any of these.
"Customer-reachable"Two standing gates. Capability→caller fails the build when a capability has no caller; route→client fails it when a server route has no client method and no reasoned exemption.
"The trust page is true"Document→code gate: every machine-checkable claim on the trust page is asserted against the running configuration, and a list of unbacked terms fails the build if they appear.
"Durable"One contract suite per store, executed twice — in memory and against a live PostgreSQL 16 that CI provisions and refuses to skip.
"Never verified live"Stated, not hidden: no Zoom account has ever installed this app, no CRM has ever received a write, no load test has run, no human has used the panel.
